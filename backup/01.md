# 第1章: Solon言語への招待

## Solonへようこそ

Solonへようこそ！

Solonは、現代のソフトウェア開発に求められる**明確さ**、**安全性**、そして**開発者の生産性**を最優先に設計された、静的型付けの多目的プログラミング言語です。

もしあなたが、
* 書くときも読むときも、意図が明確に伝わるコードを書きたい
* よくあるプログラミング上のミスを、言語の力で未然に防ぎたい
* 冗長な記述を減らし、より少ないコードで本質的なロジックに集中したい

と考えているなら、Solonはあなたのための言語です。このドキュメントは、あなたがSolonの世界を探求し、その力を最大限に引き出すためのガイドブックです。

## なぜSolonなのか？ ― 5つの哲学

Solonは、単なる機能の集合体ではありません。一貫した設計哲学が、言語の隅々まで行き渡っています。

* **明確さ (Clarity)**
    コードは書く時間より読まれる時間の方が遥かに長いものです。Solonは、誰が読んでも意図が曖昧にならない、一目で理解できる構文を追求します。

* **安全性 (Safety)**
    コンパイル時と実行時の両方で、`null`の安全な扱いや厳密な型システムなどを通じて、開発者が陥りがちな多くのエラーを防ぎます。

* **予測可能性 (Predictability)**
    言語の挙動は常に開発者の期待通りに、そして一貫して動作します。「驚き最小の法則」に基づき、安心してコードを書ける環境を提供します。

* **生産性 (Productivity)**
    ケバブケースの命名規則、パイプライン演算子、強力なクエリ構文など、直感的で強力な機能により、開発者はより少ない労力で高品質なソフトウェアを構築できます。

* **自然な明示性 (Natural Explicitness)**
    コードの重要な挙動は明示的に表現されるべきですが、それは過度な冗長さを意味しません。Solonは、簡潔さと美しさを保ちながら、必要な情報を的確に表現することを目指します。

## コードで見るSolon

百聞は一見に如かず。Solonのコードがどのようなものか見てみましょう。

以下のコードは、ユーザーに挨拶メッセージを表示する簡単なプログラムです。

```solon
/// ドキュメンテーションコメントです。
/// ユーザーに挨拶する簡単な関数を定義します。
///
/// @param name: str - 挨拶する相手の名前。
def greet-user(name: str) -> void {
  // イミュータブルな変数を定義し、文字列を補間します。
  let message: $str = $"Hello, {name}! Welcome to Solon.";

  // パイプライン演算子を使って、メッセージを出力関数に渡します。
  message |> print;
}

// プログラムのエントリーポイント
public def main() -> void {
  greet-user("World");
}
```

この短いコードの中にも、Docコメント、`kebab-case`の関数名、型アノテーション、イミュータブルな変数定義、文字列補間、そしてパイプライン演算子といったSolonの特徴が詰まっています。

## このドキュメントの構成

このドキュメントは、あなたがSolonを体系的に学べるように構成されています。

* **第2章: 基本的な要素**
    変数、データ型、演算子など、プログラミングの基礎を学びます。

* **第3章: データ構造**
    配列や構造体といった、データをまとめて扱う方法を学びます。

* **第4章: 関数と制御フロー**
    処理をまとめ、コードの流れを制御する方法を学びます。

* **第5章: オブジェクト指向**
    クラスやインターフェースを使った、大規模なプログラムの設計方法を学びます。

* **第6章: コードの編成とモジュール**
    コードをファイルや名前空間に分割し、管理する方法を学びます。

* **第7章: 高度なトピック**
    配列のクエリ構文など、Solonならではの強力な機能を探求します。
