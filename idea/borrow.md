# 所有権と借用（Ownership and Borrowing）

## 所有権とは？
- データには1つの所有者しか存在できない
- 変数に代入すると、元の変数は無効になる（ムーブ）

```Solon
let x: int32 = 10;
let y = x;
print($"{x}"); // エラー
```

## 借用とは？
- `&` で参照として渡せる（読み取り専用）
- `&$`で可変参照も可能

```Solon
let x: int32 = 10;
let y: &int32 = &x;
print($"{x}"); // エラーにならない

// yは書き換えられない
y = 11; // エラー

let $z!: &int32 = &x; // 参照先を書き換える可能性のある変数 
```

## 可変性のルール
- 可変参照は同時に1つのみ許可
- 不変参照は複数可、ただし可変参照と同時には不可
