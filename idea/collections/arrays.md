# arrays

Solon の配列は、イミュータブルがデフォルトの安全なデータ構造です。  
配列のインデックスは 0 から始まります。

## 定義と初期化

### イミュータブルな配列

```solon
let names: str[] = ["Alice", "Bob", "Charlie"];
```

- 変数 `names` は不変です。
- 配列の要素も不変です。
- 再代入も、要素の変更もできません。

### ミュータブルな変数

```solon
let $names: str[] = $["Alice", "Bob", "Charlie"];
```

- 変数 `$names` はミュータブルです。
- 配列全体を別の配列に置き換えることができます。
- 要素の変更はできません。

### ミュータブルな要素

```solon
let names: str$[] = [$"Alice", $"Bob", $"Charlie"];
```

- 変数 `names` は不変です。
- 配列の要素がミュータブルです。
- 要素の中身を書き換えることができます。

### ミュータブルな変数かつミュータブルな要素

```solon
let $names: str$[] = $[$"Alice", $"Bob", $"Charlie"];
```

- 変数 `$names` はミュータブルです。
- 配列の要素もミュータブルです。
- 配列の参照を入れ替えることも、要素を書き換えることもできます。

## 多次元配列

### ジャグ配列

```solon
let matrix: str[][] = [["a", "b"], ["c"]];
let $matrix: str$[][] = $[[$"a", $"b"], [$"c"]];
```

- 外側の配列の各要素が別々の長さの配列を持つ。

### 矩形配列

```solon
let table: str[,] = [,];
let $table: str$[,] = $[,];
```

- 行・列が固定された配列。

## インデックスアクセス

```solon
let names: str[] = ["Alice", "Bob", "Charlie"];
let name = names[0]; // "Alice"
```

要素がミュータブルな場合：

```solon
let names: str$[] = [$"Alice", $"Bob"];
names[0][0] = 'a';
```

## スライス

配列の一部分を取り出すスライス構文があります。  
スライスは半開区間（`start` を含み、`end` は含まない）です。

### スライスの暗黙的な挙動

スライスの結果が「コピー」か「ビュー」になるかは、**変数のミュータブル性**に依存します。

#### イミュータブル変数への代入

```solon
let names: str[] = ["Alice", "Bob", "Charlie"];
let part: str[] = names[0..2];
```

- 変数 `part` はイミュータブルです。
- スライス結果は新しい配列（コピー）です。

#### ミュータブル変数への代入

```solon
let $names: str$[] = $[$"Alice", $"Bob", $"Charlie"];
let $part: str$[] = $names[0..2];
```

- 変数 `$part` はミュータブルです。
- スライス結果はビュー（元の配列の一部への参照）です。

### スライスの明示的な指定

スライス結果が「コピー」か「ビュー」かを **明示的に指定** することもできます。

#### 明示的にコピーする

```solon
let names: str[] = ["Alice", "Bob", "Charlie"];
let part: str[] = clone names[0..2];
```

- `clone` を使うと、必ず新しい配列が作られます。

#### 明示的にビューにする

```solon
let $names: str$[] = $[$"Alice", $"Bob", $"Charlie"];
let $part: str$[] = borrow $names[0..2];
```

- `borrow` を使うと、必ずビュー（借用）になります。

## まとめ

| 対象                       | 記法例                                      | 説明                                   |
|----------------------------|-------------------------------------------|---------------------------------------|
| 不変の変数＋不変の要素     | `let names: str[]`                       | 配列も要素も不変                     |
| ミュータブルな変数         | `let $names: str[]`                      | 変数は再代入可、要素は不変           |
| 要素がミュータブル         | `let names: str$[]`                      | 変数は不変、要素は書き換え可能       |
| 両方ミュータブル           | `let $names: str$[]`                     | 変数も再代入可、要素も書き換え可能   |
| ジャグ配列                 | `str[][]`                                | 外側の配列の各要素が可変長の配列     |
| 矩形配列                   | `str[,]`                                 | 行と列が固定された配列               |
| スライス（暗黙：コピー）   | `let part: str[] = names[0..2]`         | 変数が不変 → コピー                  |
| スライス（暗黙：ビュー）   | `let $part: str$[] = $names[0..2]`      | 変数がミュータブル → ビュー         |
| スライス（明示：コピー）   | `let part: str[] = clone names[0..2]`   | 明示的にコピー                       |
| スライス（明示：ビュー）   | `let $part: str$[] = borrow $names[0..2]`| 明示的にビュー                       |

## おまけ：関数的な記述

配列を扱うとき、必ずしも `$` を付けてミュータブルにする必要はありません。  
不変のまま関数的に書いた方が安全で読みやすい場合もあります。

例えば以下のように、パイプラインやクエリ構文を利用します。

### パイプラインでの操作

```solon
let names: str[] = ["Alice", "Bob", "Charlie"];

let result = names
  |> filter(n => n != "Alice")
  |> map(n => n.uppercase());
```

- この場合、`names` も `result` も不変です。
- 中間の結果も新しい配列として生成されます。

### クエリ構文での操作

```solon
let names: str[] = ["Alice", "Bob", "Charlie"];

let result =
  from n in names
  where n != "Alice"
  select n.uppercase();
```

- クエリ構文でも、元の配列には影響しません。
- 結果は新しい配列です。

### まとめ

関数的な記述を使うと、`$` を付けずに安全で読みやすいコードが書けます。
一方で、性能や意図的な再代入が必要な場合は、`$` を使ってミュータブルに書くこともできます。

> 不変なコードを書けるなら書く、必要なら安全に `$` を使う。
