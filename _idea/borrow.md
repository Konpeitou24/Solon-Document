# 所有権と借用（Ownership and Borrowing）

## 所有権とは？
- データには **1つの所有者** しか存在できない  
- 変数に代入すると、元の変数は無効になる（ムーブ）

```solon
let x: int32 = 10;
let y = move x;
print!("{x}"); // ❌ エラー：x は無効
```

---

## 借用とは？
- `borrow` で参照として渡せる（読み取り専用）  
- `$borrow` で可変参照も可能

```solon
let x: int32 = 10;
let y: &int32 = borrow x;
print!("{x}"); // ✅ OK：借りているだけ

// y は書き換えられない
y = 11; // ❌ エラー

let $z: &int32 = $borrow x; // 参照先を書き換える可能性がある
$z = 42; // ✅ OK：可変借用
```

---

## 可変性のルール
- 可変借用は同時に **1つのみ許可**
- 不変借用は **複数可**
- ただし、可変借用と不変借用を同時に持つことは不可

---

## ライフタイム
- 借用は元の所有者が有効な間のみ有効  
- ライフタイム注釈はコンパイラが推論するか、必要なら明示できる  
- ダングリング参照はコンパイルエラー

---

## 関数引数と借用
- 関数に値を渡すと所有権が移る  
- 借用で渡すと所有権は移らない  
- 可変借用で渡せば関数内で書き換え可能

```solon
def show(value: &int32) -> void {
    print("Value: {value}");
}

let x: int32 = 100;
show(borrow x);
```

---

## よくあるエラーとその対処

| エラー例                         | 対処法                         |
|----------------------------------|--------------------------------|
| 借用後に元の所有権を移す         | 借用が終わるまで待つ           |
| 可変借用と不変借用を同時に行う   | どちらか一方にする            |
| ダングリング参照（無効な参照）   | ライフタイムを守る／スコープを調整 |

---

## Solon における特徴と Rust との違い

| 項目                | Rust                             | Solon                           |
|----------------------|----------------------------------|---------------------------------|
| 借用チェック         | 静的（コンパイル時）             | 静的＋簡潔な構文（`borrow`）   |
| 借用の書き方         | `&x`, `&mut x`                   | `borrow x`, `$borrow x`       |
| ライフタイム注釈     | 必要な場合は明示                 | 原則自動推論                   |
| 可変性の表現         | `mut` で変数、`&mut` で参照      | `$` で変数、`$borrow` で参照 |

## at構文と無効参照の安全な扱い

### 概要
`at` 構文は、参照先の値を明示的かつ自然な形で書き換えるための構文です。`at b = …` の形で参照先に代入を行います。もし参照先が無効（スコープ外・破棄済み）であれば、安全に処理が行われ、エラーにはなりません。

---

### 基本構文

```solon
at b = 値;
```

- `b` が有効な参照の場合 → 参照先に `値` を代入
- `b` が無効な参照の場合 → 代入は行われず、null 相当を返す

---

### 返り値
`at` は式としても使え、以下のように利用できます。

```solon
if at b = 10 {
    print("書き換え成功");
} else {
    print("参照先が無効だった");
}
```

- 有効参照なら `true` または `Some`
- 無効参照なら `false` または `None`

---

### 使用例

#### 有効参照の場合

```solon
let x: int32 = 5;
let $b: &int32 = $borrow x;

at b = 42;
// → x が 42 になる
```

---

#### 無効参照の場合

```solon
let $b: &int32;
{
    let x: int32 = 10;
    $b = $borrow x;
}
// x はスコープから消える

at b = 99;
// → 参照先が無効のため、エラー
```

---

### メリット
- 短く自然な構文
- 参照先が無効な場合も安全
- Optionalな返り値で状態を確認可能
- エラーでプログラムが止まることがない
