# Solon: `default` フィールドの仕様

`default` 修飾子は、クラスのインスタンスが暗黙的にそのフィールドの値として振る舞うようにするための指定です。  
ただし、厳密な同一性比較には影響しません。


## 定義

クラスのフィールドに `default` を付けると、インスタンスがそのフィールドの値として扱われます。

```solon
class Foo {
  default public let x = 0;
}
```

この場合、`Foo` のインスタンスは暗黙的に `x` として振る舞います。


## 振る舞い

### 代入
`default` フィールドは、代入や暗黙の型変換の場面で使用されます。

```solon
let foo = new Foo();
let value: int32 = foo; // OK: value に foo.x が代入される
```


### 関数呼び出し
関数に渡す際も、`default` フィールドが使用されます。

```solon
def printValue(val: int32) { … }

let foo = new Foo();
printValue(foo); // OK: foo.x が渡される
```

### 厳密な比較
`is` 演算子は、インスタンスのメモリ上の同一性を比較するため、`default` は無視されます。

```solon
let foo = new Foo();

if foo is foo.x {
  print("hello"); // 実際には実行されない
} else {
  print("ng");    // こちらが実行される
}
```

## 制約

- `default` は1つのクラスに対して1つまで指定可能です。
  - 複数の `default` がある場合はコンパイルエラー。
- クラスが暗黙的に値を提供するのは、代入や関数呼び出しなど「値として扱う場面」に限定されます。
- 厳密な比較 (`is`) では無効であり、インスタンス本体とフィールドは別のものとして扱われます。

## まとめ

| 操作                           | 結果                                |
|--------------------------------|-------------------------------------|
| 代入                            | `default` フィールドが代入される   |
| 関数引数                        | `default` フィールドが渡される     |
| `is` 比較                       | 無視される（インスタンス ≠ フィールド） |
