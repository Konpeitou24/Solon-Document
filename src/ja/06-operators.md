# 06 Operators

## 基本的な算術演算子と演算子の空白

四則演算などに使われる一部の演算子は、その記号の両端に空白を含める必要があります。

これには理由があります。

- 命名と演算子の混同防止
- 視認性の向上
- 自動成型ツールとの親和性

Solonは言語設計レベルでコードの長期的な読みやすさを保証しています。


`.`演算子や`?.`, `()`の間など慣例的に空白を含めない演算子には空白は必要ありません。

以下の通りです。(実際には値は使用される必要があります)

### 例

#### 加算

```
// 正常
a + b

// エラー！
a+b
a+ b
a +b
```

#### 減算

```
//正常
a - b

// エラー！
a-b
a- b
a -b
```

#### 乗算

```
// 正常
a * b

// エラー！
a*b
a* b
a *b
```

#### 除算

```
// 正常
a / b

// エラー！
a/b
a/ b
a /b
```

#### 剰余

```
// 正常
a % b

// エラー！
a%b
a% b
a %b
```

## UFO演算子

2つの値を比較し、大小関係を数値で表現することで、ソートや条件分岐を簡潔に記述できます。

- 左辺 > 右辺の場合、1を返す。
- 左辺 == 右辺の場合、0を返す。
- 左辺 < 右辺の場合、-1を返す。

```
let a: int32 = 5;
let b: int32 = 3;

let result: int32 = a <=> b; // resultは1になります
```


## 絶対値演算子

変数や値の絶対値を求める演算子です。

以下の通りに表現されます。演算子と、変数や値との間には空白を必要としません。

```Solon
let value: float64 = -10;
let abs: float64 = |value|; // 10
```

### プレースホルダ _ の利用

Solonでは、関数呼び出し時にアンダースコア（`_`）を使って「プレースホルダ」を指定できます。

これにより、部分適用（部分的な引数の固定）が簡単に行えます。

```Solon
def multiply(a: int32, b: int32) -> int32 {
  return a * b;
}

// 'double' は、1つの int32 引数 (b) を受け取り、2 * b を計算する新しい関数
// multiply(2, _) を呼び出すと、新しいラムダ関数 (b) => multiply(2, b) が生成されるイメージ
let double = multiply(2, _);
let result_double = double(5); // result_double は 10 (2 * 5)
```

このプレースホルダ機能は、`@curried!`属性がなくても通常の関数で利用できます。

### 無名関数（ラムダ式）

Solonでは、無名関数（ラムダ式）をサポートしています。

- ラムダ式の引数リストは必ず `()` で囲みます。
- ラムダ式は例外的に型推論が有効です。
- 記法：`(引数リスト) => 処理内容`
- 引数がない場合も `()` を省略できません。

#### 例

```Solon
// 何も引数を取らず、常に "Hello!" という文字列を返す関数
let sayHello = () => u8"Hello!";
let greeting = sayHello(); // greeting は u8"Hello!"

// 複数の引数を持つラムダ式
let add = (x, y) => x + y;
let result = add(2, 3); // result は 5
```

このように、Solonのラムダ式は簡潔かつ型推論を活用できる柔軟な記法です。

### パイプライン

Solonでは`|>`によりパイプライン処理をサポートします。

従来のネストされた関数よりも、直感的で読みやすい記述ができるような工夫です。

型推論が有効です。

```Solon
引数 |> 関数;
```

活用例

```Solon
// 従来のネスト
let result = process3(process2(process1(data)));

// Solonのパイプライン
let result = data
            |> process1
            |> process2
            |> process3;
```

引数を複数渡す場合は以下の通りです。

```Solon
// カリー化可能関数を定義します。
@curried!
def sum(x: int32, y: int32, z: int32) -> int32 {
  return x + y + z;
}

let result = 10
            |> sum // 10がsumのxに渡される。結果は (y) => (z) => 10 + y + z を返す関数
            |> sum(100) // 100が上記の関数のyに渡される。結果は (z) => 10 + 100 + z を返す関数
            |> sum(1000); // 1000が上記の関数のzに渡される。最終結果は 10 + 100 + 1000 = 1110
```
