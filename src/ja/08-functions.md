# 関数定義

Solon言語では関数の定義を`def`で行います。
以下の通りです。

## 書き方

```Solon
def 関数名(引数名: 型) -> 戻り値の型 {
    # 関数の処理
}
```

### 例

```Solon
def calculate-area(width: int32, height: int32) -> int32 {
    # 説明のために面積の計算
    let area = width * height;
    return area;
}
```
## ネストされた関数

Solonでは関数をネストすることが可能です。

```Solon
def outer(x: int32) -> int32 {
  def inner(y: int32) -> int32 {
    return y * 2;
  }
  return inner(x) + 1;
}
```

## 関数のオーバーロード

Solonは関数のオーバーロードをサポートしています。

- 同じ名前で、引数の数や型が異なる関数を同一ブロック内に定義できます。
- 戻り値の型が異なるだけではオーバーロードとはみなされません。

```Solon
def print(value: int32) -> void {
  // int32型の値を出力
}
def print(value: str) -> void {
  // 文字列を出力
}
// これはOK

def print(value: int32) -> int32 {
  // 戻り値の型が違うだけ → エラー！
}
```

このように、引数の数や型が異なる場合のみオーバーロードが可能です。

## カリー化関数

Solonでは、関数に`@curried!`属性を付与することで、カリー化（Currying）をサポートしています。

```Solon
@curried! // この属性を付けることで、以下の関数がカリー化可能になる
def add(x: int32, y: int32, z: int32) -> int32 {
  return x + y + z;
}
```

オプトインにしている理由としては、ほとんどの関数がすべての引数を一度に受け取る方が直感的で、コードの明確さと生産性を維持できるためです。

`@curried!`属性が付いている関数は、以下の2通りの方法で呼び出すことができます。

- **通常の呼び出し（全ての引数を一度に渡す）**
  - 例：`let result1 = add(1, 2, 3); // result1 は 6`
- **カリー化された呼び出し（引数を一つずつ渡す）**
  - 例：`let result2 = add(1)(2)(3); // result2 も 6`

`!`（感嘆符）は、Solonの`@curried!`のように属性の後に付けることで、
**「通常の動作ではない、特別な、あるいは強力な効果がある」** ことを示します。

これは、Rubyの`sort!`メソッドが「元の配列を破壊的に変更する」ことを示すのと似ています。

Solonの場合、`@curried!`が関数に付くと、その関数は単なる普通の関数ではなくなります。
コンパイラがその関数の型や呼び出し方を自動的に「カリー化された形式」に変換し、引数を一つずつ渡せるようにします。

つまり、`!`は開発者に対して、
**「この属性は単なる情報ではなく、言語の振る舞いを大きく変える、見逃せない指示だ」**
という明確なサインを送る役割を担っています。

## 数学関数

Solonでは、関数に`@math!`属性を付与することで、数学的記述以外の処理を制限できます。

許可される要素は以下の通りです。

1. 数値リテラル:
   - 例:`1`, `100`, `0.5`, `-7`など、直接記述された数値。
2. 数値型の引数:
   - 関数に渡される引数で`int8`, `uint16`, `float32`, `float64`などの数値型として宣言されている変数。
3. `@math`属性を持つ関数の呼び出し:
   - 同様の数学的関数
4. 基本的な算術演算子
   - `+`加算
   - `-`減算
   - `*`乗算
   - `/`除算
   - `%`剰余
   - `^`べき乗
5. 比較演算子
   - `==`等しい
   - `!=`等しくない
   - `<`より大きい
   - `>`より小さい
   - `<=`以下
   - `>=`以上
   - `<=>`UFO演算子
6. 論理演算子
   - `and`AND
   - `or`OR
   - `xor`XOR
   - `not`NOT
7. 条件分岐
   - `condition ? true_value : false_value`三項演算子
   - `if`分岐
8. その他
   - `|value|`絶対値演算子が利用できます。
  

また、ミュータブルな変数の定義や使用、ブロック外の変数の使用は許可されません。

## プレースホルダ _ の利用

Solonでは、関数呼び出し時にアンダースコア（`_`）を使って「プレースホルダ」を指定できます。

これにより、部分適用（部分的な引数の固定）が簡単に行えます。

```Solon
def multiply(a: int32, b: int32) -> int32 {
  return a * b;
}

// 'double' は、1つの int32 引数 (b) を受け取り、2 * b を計算する新しい関数
// multiply(2, _) を呼び出すと、新しいラムダ関数 (b) => multiply(2, b) が生成されるイメージ
let double = multiply(2, _);
let result_double = double(5); // result_double は 10 (2 * 5)
```

このプレースホルダ機能は、`@curried!`属性がなくても通常の関数で利用できます。

## 無名関数（ラムダ式）

Solonでは、無名関数（ラムダ式）をサポートしています。

- ラムダ式の引数リストは必ず `()` で囲みます。
- ラムダ式は例外的に型推論が有効です。
- 記法：`(引数リスト) => 処理内容`
- 引数がない場合も `()` を省略できません。

### 例

```Solon
// 何も引数を取らず、常に "Hello!" という文字列を返す関数
let sayHello = () => u8"Hello!";
let greeting = sayHello(); // greeting は u8"Hello!"

// 複数の引数を持つラムダ式
let add = (x, y) => x + y;
let result = add(2, 3); // result は 5
```

このように、Solonのラムダ式は簡潔かつ型推論を活用できる柔軟な記法です。

## パイプライン

Solonでは`|>`によりパイプライン処理をサポートします。

従来のネストされた関数よりも、直感的で読みやすい記述ができるような工夫です。

型推論が有効です。

```Solon
引数 |> 関数;
```

活用例

```Solon
// 従来のネスト
let result = process3(process2(process1(data)));

// Solonのパイプライン
let result = data
            |> process1
            |> process2
            |> process3;
```

引数を複数渡す場合は以下の通りです。

```Solon
// カリー化可能関数を定義します。
@curried!
def sum(x: int32, y: int32, z: int32) -> int32 {
  return x + y + z;
}

let result = 10
            |> sum // 10がsumのxに渡される。結果は (y) => (z) => 10 + y + z を返す関数
            |> sum(100) // 100が上記の関数のyに渡される。結果は (z) => 10 + 100 + z を返す関数
            |> sum(1000); // 1000が上記の関数のzに渡される。最終結果は 10 + 100 + 1000 = 1110
```

## 関数型

Solonでは関数を型として扱うことができます。それは主に無名関数などを格納したりする際に利用でき、通常の関数は値として扱われません。

```
// 引数なしの場合
function<戻り値の型>

// 引数ありの場合
function<引数の型, 戻り値の型>
```
